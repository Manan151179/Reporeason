## Input

**Query:** `RAG chatbot`

---

## Run the app

```bash
streamlit run graphsearch/graph_app.py
```

Open the URL Streamlit prints (usually `http://localhost:8501`), type the query above,
and click **Search**.

**Offline alternative** — regenerate every benchmark number from the committed results
(no services needed):

```bash
python reproduce.py
```

## What this run shows

- **Graph expansion works.** The initial GitHub search returned 15 repos; the knowledge
  graph recalled **10 more** for 25 total. Result **#2 (Langchain-Chatchat, 38k★)** carries
  the `🔗 graph-found` badge — a strong repo the keyword search alone missed. This is the
  recall step from [`graphsearch/graph_expand.py`](../graphsearch/graph_expand.py).
- **Fit, not stars.** Results are ordered by the hybrid fit score, not raw popularity:
  kotaemon (fit 0.8623, 25.9k★) ranks above the more-starred Langchain-Chatchat
  (fit 0.7193, 38.7k★), because its description is a more direct semantic match to the query.
- **Every result is explained.** Each card's "Why this fits" line is generated by
  `qwen2.5-coder:7b`, grounded only in the repo's own name, description, topics, and
  language — so the ranking is transparent, not a black box.
